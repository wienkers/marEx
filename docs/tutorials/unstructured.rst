=================
Unstructured data
=================

Analysis on irregular meshes from ocean models such as FESOM, ICON-O, and
MPAS-Ocean. The same workflow applies as for gridded data; grid topology is
supplied via :func:`marEx.specify_grid`. Work through the notebooks in order.
